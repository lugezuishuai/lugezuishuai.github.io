# Composition
Create a playful educational workbench where a friendly AI assistant assembles large rounded building blocks into a clear instruction path. Distinguish the blocks visually: one blank block, several example-card blocks, a sequence of stepping-stone blocks, a rule/constraint block, and a magnifying-glass block. The assembled path leads to a polished answer card. Make the metaphor “different prompt techniques are reusable building blocks” immediately understandable.

Use macaron pastel colors on warm cream, clean bold charcoal outlines, simple geometric icons, flat fills, subtle paper grain, soft shadows, and generous whitespace.

Avoid computer terminals, cyberpunk styling, glowing networks, complicated flowcharts, realistic people, readable words, letters, numbers, logos, or watermarks.
