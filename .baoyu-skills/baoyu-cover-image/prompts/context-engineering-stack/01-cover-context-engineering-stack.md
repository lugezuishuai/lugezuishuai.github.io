# Composition
Create an educational cutaway illustration of a tall, friendly modular cabinet with six clearly separated drawers. Each drawer contains one large recognizable object: a conversation card, a prompt pencil, a library book with magnifier, a toolbox, a memory notebook, and an archive box. A simple AI assistant stands beside the cabinet selecting the right drawer for a task card. The cabinet should communicate a complete, layered technology stack without resembling a server rack.
