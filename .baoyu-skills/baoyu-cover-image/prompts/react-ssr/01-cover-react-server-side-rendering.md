# Composition
Create a friendly restaurant-kitchen metaphor for server-side rendering. On the left, a server kitchen assembles separate page ingredients—header card, content card, image card, and button card—onto one complete browser-page tray. A conveyor carries the already assembled page to a browser window on the right. Beside the browser, a small hand connects a simple interaction plug to the page, representing hydration. The metaphor must instantly communicate “the server prepares the page first, then the browser activates it.”

Use a warm cream background, macaron pastel blocks, clean uniform charcoal outlines, rounded flat-vector objects, subtle paper texture, soft shadows, and generous whitespace.

Avoid realistic food, dark server rooms, neon, cyberpunk, circuit boards, complex code screens, readable words, letters, numbers, logos, or watermarks.
