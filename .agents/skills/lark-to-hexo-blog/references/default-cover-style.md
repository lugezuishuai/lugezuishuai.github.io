# Built-in cover style: terminal-editorial-light

Use this preset when the user does not choose a style. Present it as the recommended default and follow `baoyu-cover-image` confirmation policy.

| Dimension | Value |
|---|---|
| Type | `conceptual` |
| Palette | `cool` |
| Rendering | `flat-vector` |
| Text | `title-only` |
| Mood | `balanced` |
| Font | `clean` |
| Aspect | `16:9` |
| Language | Match the article title |

## Art direction

Create a clean editorial technology illustration designed for the blog's white default theme:

- Warm white or very pale gray background with generous breathing room.
- Terminal green and restrained cyan/blue accents, with charcoal outlines and high legibility.
- One strong conceptual visual metaphor derived from the article, supported by subtle grids, nodes, arrows, code-window geometry, or architecture-diagram motifs.
- Crisp flat-vector rendering with light depth and restrained shadows; avoid glossy 3D, noisy gradients, photorealistic people, logos, and watermarks.
- Keep the exact article title readable and concise. Do not invent a subtitle.
- Maintain a strong center or left-offset visual anchor and leave 40–60% breathing room.

If generated text is misspelled or illegible, regenerate from a corrected prompt or use a lower-text variant. Never paint over a generated bitmap to repair text.
